2. One-time Google project setup
{% if client_ready %}Review or change project configuration{% else %}Prepare a project or import its setup profile above{% endif %}

Your organization can prepare one Google project and Groups helper for everyone. Each user only imports that project’s Boreal setup profile once and signs in with their own account. If it is already configured, keep these settings.

Project owner instructions
  1. Choose the shared Boreal project in Google Cloud Console. Enable Google Drive API for Drive or private Persons Sheets, and Apps Script API for My Groups.
  2. Configure the OAuth audience and a Desktop app client. For an organization deployment, use its internal audience when appropriate. For external production use, complete the required Google verification. External apps left in Testing have seven-day refresh tokens.
  3. Download the Desktop client JSON. Each installation imports the same application configuration through Google project credentials. User credentials are created separately during sign-in.
  4. For My Groups, create an Apps Script project. Copy Code.gs and appsscript.json into it (enable “Show appsscript.json” in Project Settings).
  5. In Apps Script Project Settings, change the Google Cloud project to the project number of the same Boreal project. Deploy → New deployment → API executable. Allow the intended users to execute it. Copy the deployment ID below. Keep the helper in its owning account and use versioned deployments.
  6. Users approve group-viewing and account identity access, plus Drive access for selected services. My Groups does not require an Admin SDK role. Organization policy may require approval of the application once.
