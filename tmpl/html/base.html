Existing Rclone process detected

An Rclone process was already running before this BOREAL session. It may be left over from an earlier BOREAL run, but it could also belong to another application or an active transfer.

Before stopping it: confirm that no Rclone transfer, mount, or other application is using the process. BOREAL will not stop it automatically.

Linux or macOS

Open Terminal and identify the process:

ps -ax -o pid=,command= | grep '[r]clone'

After confirming the PID is stale, request a normal shutdown:

kill -TERM <PID>

Windows PowerShell

Identify existing Rclone processes:

Get-Process rclone

After confirming the PID is stale, request that it stop:

Stop-Process -Id <PID>

After the stale process has stopped, quit and restart BOREAL. If the process belongs to another application, leave it running; current BOREAL builds use automatically selected WebGUI ports.
