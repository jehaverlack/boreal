Create Google Client ID

Create Google OAuth Desktop app credentials for BOREAL, then download the JSON file.

Step 1 of 4 Google Cloud Console opens in a new tab

1. Choose a Google Cloud project

Choose an existing Google Cloud project or create a new project for BOREAL.

Google may open a recently used project. Confirm the project before continuing.
Choose or Create a Project

2. Enable APIs for your services

  1. For Drive or a linked Persons Sheet, open the Google Drive API setup page.
  2. For Groups, also enable Admin SDK API in the same project.
  3. Confirm that Google shows the project selected in step 1.
  4. Click Enable.
Open Google Drive API Setup

3. Configure Google Auth Platform

Complete the initial Google Auth Platform setup for the selected project.

  1. If prompted, click Get Started.
  2. Set the app name to BOREAL and select a user support email.
  3. Choose Internal for organization-only use; otherwise choose External.
  4. Enter a contact email, accept the Google API Services User Data Policy, and create the configuration.
  5. For an External app in testing, add every account that will use BOREAL under Audience.

When the configuration is complete, return here and click Next. You will create the OAuth client in Step 4.

Open Auth Platform Overview

4. Create and download the OAuth client

Open the Clients page for the same Google Cloud project.

Open OAuth Clients
  1. Click + Create client.
  2. Set Application type to Desktop app.
  3. Set Name to BOREAL and click Create.
  4. In the confirmation dialog, click Download JSON and save the credentials file.
Important: Download the JSON credentials before closing the OAuth client dialog.
