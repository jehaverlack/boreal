Google setup guide

Follow the steps for the Google sources you use. This guide opens Google’s configuration pages; it does not change your Cloud project automatically.

1. Select the Boreal project

Open the Google Cloud Console API Library. Check the project selector at the top and choose the project used by Boreal’s Google Client ID.

2. Enable the APIs

For Drive or a linked Persons Sheet, search for Google Drive API, select it, and click Enable.

For Groups, search for Admin SDK API, select Admin SDK API, and click Enable. Check that the same Boreal project is still selected.

Google Drive API · Admin SDK API

3. Configure the Desktop OAuth client

Configure the project’s OAuth consent screen for your audience. Create an OAuth client of type Desktop app, download its JSON file, and upload it through Boreal’s Google Client ID setup. If the app is in testing, add your account as a test user when required.

Open Google Auth Platform clients

4. Connect and grant access

Save your source choices in Settings first. For Drive or a linked Persons Sheet, authorize the read-only connection in Drive connections. Persons CSV import and manual entries need no Google connection.

For Groups, open Google Groups, connect a Workspace account with group-read privileges, and grant both read-only group and membership permissions. An administrator may need to allow the app in Workspace API controls. Enabling Admin SDK in Cloud Console alone does not grant Workspace privileges.

Groups scopes: admin.directory.group.readonly and admin.directory.group.member.readonly. Select the connected sources in Update to fetch their metadata.
