Google setup guide

Follow the steps for the Google sources you use. This guide opens Google’s configuration pages; it does not change your Cloud project automatically.

1. Choose your Google services

Open Google connection. Choose Drive, My Groups and your optional private Persons Sheet. Migration write access is optional.

2. Configure the project once

Your project owner enables Google Drive API for Drive and private Sheets, and Apps Script API for My Groups. Use the same project for the Desktop OAuth client and Groups helper. Import the Desktop client JSON through Google project credentials.

3. Prepare My Groups

If using Groups, deploy the helper once as an Apps Script API executable and allow your users to execute it. Google connection provides the helper files and instructions. Ordinary My Groups users do not need Admin SDK privileges.

4. Connect once, then update

On Google connection, approve your selected permissions and review each access check. After setup, use Update metadata. Boreal refreshes authorization automatically. Revoked access or additional permissions can require consent again.

For durable external connections, complete production OAuth setup; Testing refresh tokens expire after seven days.
