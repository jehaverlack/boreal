Google setup guide

Follow the steps for the Google sources you use. This guide opens Google’s configuration pages; it does not change your Cloud project automatically.

1. Select the Boreal project

Open the Google Cloud Console API Library. Check the project selector at the top and choose the project used by Boreal’s Google Client ID.

2. Enable Google Drive API

For Drive or a private Persons Sheet, enable Google Drive API in the selected Boreal project. If it is already enabled, continue.

3. Configure the Desktop OAuth client

Configure the project’s OAuth consent screen for your audience. Create an OAuth client of type Desktop app, download its JSON file, and upload it through Boreal’s Google Client ID setup. If the app is in testing, add your account as a test user when required.

Open Google Auth Platform clients

4. Authorize your storage remote

Open Storage remotes and set up or reconnect my-drive-ro for Drive inventory, downloads and private Persons Sheets. Add my-drive-rw only for migrations; it can use a different destination account.

Rclone opens Google sign-in and renews access for later updates. After setup, use Update metadata. Persons CSV import and manual entries require no Google authorization.
