Google setup guideStep 1 of 5

Open Google with the button in each step, follow the instructions, then return here to continue. Upload your downloaded JSON file in step 5.

Step 1. Choose a Google Cloud project

Open Google Project Selection

Opens in a new tab. Keep this guide open.

  1. Choose the Google account you want to use for setup.
  2. Select an existing project, or click Create project and name it BOREAL.
  3. Confirm that your selected project appears in the Google Cloud header. Use this same project for steps 2–4.
Show example screenshots

When you have finished, return here and select Proceed to Step 2.

Step 2. Enable the Google Drive API

Open Google Drive API Setup

Opens in a new tab. Keep this guide open.

  1. Confirm that Google shows the project you selected in step 1.
  2. Click Enable for the Google Drive API. If it is already enabled, you can continue.
Show example screenshots

When you have finished, return here and select Proceed to Step 3.

Step 3. Configure Google Auth Platform

Open Google Auth Platform

Opens in a new tab. Keep this guide open.

  1. If prompted, click Get Started. If the project is already configured, review its Branding and Audience settings.
  2. Enter BOREAL as the app name and choose your user support email.
  3. Choose Internal if available and only people in your organization will use the app. Otherwise, choose External.
  4. Enter your contact email, accept the required policy, and finish creating the configuration.
  5. For an External app in testing, open Audience → Test users → Add users and add each Google account you will connect to BOREAL.

When you have finished, return here and select Proceed to Step 4.

Step 4. Create the client and download JSON

Open Google OAuth Clients

Opens in a new tab. Keep this guide open.

  1. Click + Create client in the same Google Cloud project.
  2. Choose Desktop app as the application type.
  3. Enter BOREAL as the name and click Create.
  4. Click Download JSON and save the file before closing the confirmation dialog.
Show example screenshots

When you have finished, return here and select Proceed to Step 5.

Step 5. Upload your JSON file

  1. Select the original JSON file you downloaded in step 4.
  2. Click Upload JSON to save it in BOREAL.

BOREAL saves this file locally in its private configuration directory.

After uploading, use Manage Remotes to connect your Google account. Use my-drive-ro for inventory and downloads; add my-drive-rw when you need a migration destination.
